# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues,
discussions or pull requests.

Email **security@antispamguy.org** with:

- a description of the issue and its impact;
- steps to reproduce it;
- the affected commit or version;
- any mitigation you would suggest.

If you would like to encrypt your report, ask for our PGP key in your first
message and we will send it.

## What to expect

| Stage | Target |
|---|---|
| Acknowledgement | within 48 hours |
| Triage and severity assessment | within 7 days |
| Updates while we investigate | at least weekly |
| Disclosure | coordinated with you, normally after a fix is released |

## Scope

This policy covers the code in this repository. A vulnerability in a service
somebody else operates using this code should also be reported to that
operator.
